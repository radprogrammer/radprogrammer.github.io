Open source for Delphi developers.

Alongside our commercial tools, RAD Programmer publishes free, permissively licensed Delphi libraries and sample projects — small, focused, dependency-light code you can drop into your own projects and read end to end. Everything here lives on github.com/radprogrammer.

MIT & Apache-2.0 Pure Object Pascal No runtime dependencies

The projects

radNullableTypes

Focused nullable and tri-state value types for Delphi — TNullable<T> and TTriState<T> — that start null by construction and unwrap explicitly, so a null never escapes unnoticed.

MIT Delphi 10.4+ Available
Learn more →
radJSON

An object- and record-oriented JSON serializer for Delphi that streams straight to and from text through RTTI — no intermediate System.JSON DOM — with a single, richly configurable options record.

Delphi In development
Learn more →
radAuthenticator

A TOTP two-factor-authentication sample for Delphi with Google Authenticator–compatible one-time codes, backed by a five-part blog series that walks through building it.

Apache-2.0 TOTP / 2FA Available
Learn more →
